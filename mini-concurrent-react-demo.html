What this demonstrates—and what is simplified

This is a custom teaching renderer, not React. It uses a MessageChannel host scheduler, microtask root scheduling, two toy lane bits, an explicit Fiber traversal, current/alternate objects, a persistent update queue, query-only Results memoization, and a synchronous snapshot commit. It omits hooks, real DOM reconciliation, errors, nested Suspense, hydration, lane expiration, multiple roots, and View Transitions. Its 5 ms budget is a checkpoint threshold, not a maximum task duration.

The trace is diagnostic UI outside the renderer. It may update while the renderer is paused. Result cards change only during a commit. The scripted button injects the second update in a later task after the first transition yield; that makes interruption reproducible without relying on typing speed. Pressing keys yourself exercises browser input tasks.
